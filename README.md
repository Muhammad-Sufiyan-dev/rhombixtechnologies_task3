# 📚 Book Library Web App

A responsive and interactive **Book Library Web App** built with HTML, Tailwind CSS, and JavaScript.

This project was developed as **Task 3 for the Rhombix Technologies Internship**.

## 🚀 Live Demo

https://book-library-seven-eta.vercel.app/

## ✨ Features

* 🔍 Search books by title or author
* 📂 Filter books by category
* 📖 Borrow books
* ↩️ Return borrowed books
* 📋 Borrowing history
* 💾 LocalStorage for saving borrowing data
* 🌙 Dark/Light theme
* 📱 Responsive design for desktop and mobile
* ☰ Mobile navigation menu
* ⚡ Interactive user interface

## 🛠️ Technologies Used

* **HTML5** — Structure of the web page
* **Tailwind CSS** — Styling and responsive design
* **JavaScript** — Interactivity and functionality
* **LocalStorage** — Saving borrowing history
* **Lucide Icons** — Interface icons
